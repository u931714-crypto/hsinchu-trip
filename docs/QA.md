# Hsinchu Trip — Optional QA Guide

## 部署原則

推送至 `main` 後，GitHub Actions 直接部署 GitHub Pages。部署不依賴 CI／QA 檢查，也不需要人工核准或手動啟動測試。

## 可選的 ChatGPT 輔助檢查

只有在使用者主動要求檢查時，ChatGPT 才讀取 GitHub 最新版本與本次變更，協助檢視：

| 項目 | 檢查內容 |
|---|---|
| 初始畫面 | 主要區塊、景點清單與地圖初始化 |
| 編輯模式 | 進入及離開編輯狀態 |
| 行程時間 | 修改起始時間、停留時間及時間計算 |
| 復原 | Undo 是否恢復前一狀態 |
| 景點排序 | 手動調整順序後資料是否一致 |
| 替代景點 | 加入及移除替代景點 |
| 衝突提醒 | 時間或營業時間衝突提示 |
| 資料保存 | 重新整理後資料是否符合預期 |

### 結果定義

- **PASS**：有明確證據支持該項檢查通過。
- **FAIL**：發現可重現的錯誤或程式缺陷。
- **NOT VERIFIED**：只有程式碼分析，或缺少實際瀏覽器驗證。

這份指引是可選的工作方式，不是部署條件。ChatGPT 不會將程式碼推論假稱為瀏覽器實測，也不會在未經要求時自動修改程式。

## 限制

- 不使用 OpenAI API。
- 不要求固定輪數的測試。
- 不設置 CI／QA 部署閘門。
- 不自動修改正式程式碼。
