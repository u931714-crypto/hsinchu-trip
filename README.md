# 新竹一日遊行程規劃

以 GitHub Pages 發布的單頁行程工具。

## 部署
每次推送至 `main` 分支，GitHub Actions 會自動部署網站。

## 網站
部署完成後網址為：
https://u931714-crypto.github.io/hsinchu-trip/

## 功能
- Leaflet / OpenStreetMap 行程地圖
- 行程時間動態計算
- 拖曳調整順序、抵達紀錄、復原
- 景點開放時間與衝突提醒
- 行動裝置版面


## 部署狀態
GitHub Pages 使用 GitHub Actions 部署；推送至 `main` 會觸發發布流程。
